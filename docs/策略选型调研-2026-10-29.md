3. **我们要补的不是"又一个打分公式"，而是三种能力**：① 轮动（现在只会选个股，不会换板块）；② 择时/仓位（现在永远满仓做多，靠 `ma20>ma60` 硬门槛挡熊市）；③ 事件与微观结构（现在完全不用涨停、换手、筹码、资金流）。
4. **我们发现一个硬约束必须先说**：打板/涨停这类事件策略，我们**没有历史数据**——市场情绪快照只从 2026-10-27 开始采集，至今 2 天。这不是策略不好，是**没法回测**，所以事件驱动类只能列为"需先补数据"。
5. **反过来有两个好消息**：① 日线里的 `turnover`（换手率）2021 年至今**覆盖率 100%**；② 有了换手率就能反算出**全历史的流通市值**——`流通市值 = 成交额 ÷ 换手率`，实测验证过平安银行/茅台/宁德/比亚迪全对（见 4.2 节）。再加上**申万一级行业映射已经落盘**（5220 只、31 个行业），这意味着"小市值"和"行业轮动"这两条线**现在就能做**，不需要新数据源。

**Top 3 建议（详见第 5 节）**：① **均线收敛因子 PCF/TRCF**——一个 `rolling.std()`，纯现有数据，加完之后 7 个策略同时多一个维度；② **动量因子方向修正**——现有动量策略用的是「20 日涨幅」，而研报实测 A 股裸涨幅动量 **IC 全为负**，这是修 bug 不是加功能，约 1 小时；③ **RRG 行业轮动**——补上"行业/轮动"这个现有策略完全没有的维度，代码和文档都是本次调研里最完整的。三个都不需要新买数据源。

## 1. 我们现在的 7 个策略，到底哪里"过时"了

先把话说准：**不是参数过时，是结构过时**。7 个策略拆开看，骨架完全一样：

```
选股池（硬门槛 ma20 > ma60，多数策略都有）
   ↓
打分（技术面 6 个指标 + 基本面 3 个粗分，加权）
   ↓
买前 5 名
   ↓
固定 ATR 止盈/止损 + 固定持有 N 天
```

这个骨架有 5 个结构性局限，逐条对得上代码：

| # | 局限 | 具体表现（可对照代码） | 后果 |
|---|---|---|---|
| 1 | **策略之间高度同质** | 趋势跟随、动量、突破三个策略的技术面都是同一批指标（ma/rsi/atr/macd/量比），只是权重不同；价值、段永平、李录三个都是 value/growth/quality 三项加权，只是权重不同 | 跑出来的前 5 名大概率重复，分散化是假的 |
| 2 | **只会做多、熊市只能靠硬门槛** | `ma20 > ma60` 是 4 个策略的硬性入选条件 | 熊市直接空仓（这没错），但没有"空仓以外的选择"：不能降仓、不能对冲、不能做超跌反弹 |
| 3 | **没有轮动能力** | 打分是**个股横截面**排序，完全没有行业/板块/风格层面的比较 | 2021–2024 小微盘、2023 AI、2024 红利，每一波风格都吃不到 |
| 4 | **持有期写死** | `hold_days` 固定 15 / 20 / 30 / 60 / 90 天 | 波动大的票 30 天太短，波动小的票 90 天太长；ATR 止损虽自适应，持有期不自适应 |
| 5 | **完全不用微观结构数据** | 换手率 `turnover` 有数据但没进任何因子；涨停池、连板数、封板资金、炸板次数**已在采集**（`data/processed/market/`）但没进策略 | 短线最强的信号源（涨停强度、筹码集中度、封板质量）整块浪费 |

另外两个"字段层面"的空白：**没有"总市值"**（有了 `turnover` 只能反推**流通市值**，见 4.2——总市值需要总股本，我们没有）；**没有财报披露日**（有 `updated_at`，但不是公告日）。这两个直接影响小市值策略和财报类事件策略的"防未来函数"。

> 一句话：现有策略是**"个股计时器"**，缺的是**"市场温度计 + 板块地图 + 事件雷达"**。这次调研就按这三块去找。

## 3. 六大类候选

每一类先给一句"这一类要解决什么问题"，再逐个候选。每个候选固定看 9 项，其中**「用我们现有数据能不能算」**是最关键的筛选条件。

### 3.1 趋势跟随

**这一类要解决什么**：现有趋势跟随用 `ma20 > ma60` 判方向、用 ATR 倍数做止损。问题不在"判方向"，而在**"什么时候下车"是拍脑袋的**——`atr_n_stop=3.5` 这个参数没有任何依据。这一类里最值钱的不是新指标，而是**更好的离场规则**。

> **一个必须说清楚的现实**：这一类 8 个候选里，**没有一个是"5580 只股票横截面选股"**，全部是"单标的择时"或"指数级 0/1 择时"。它们能进本系统的方式是**改造**——要么改成个股级信号，要么接在仓位/择时层。

#### 候选 1：Parabolic SAR（抛物线转向）⭐ 推荐（改造成本最低）

| 项目 | 内容 |
|---|---|
| 来源 | `je-suis-tm/quant-trading`（★11149）`Parabolic SAR backtest.py`；同规则也见 QuantsPlaybook 复现 |
| **一句话赚什么钱** | 涨势里止损位跟着价格往上爬，涨得越快爬得越快；一旦跌破就反手。本质是**"移动止损 + 自动加速"**。 |
| **核心规则（可照抄的递推）** | `SAR(t+1) = SAR(t) + AF × (EP − SAR(t))`<br>EP = 当前趋势内的极值（上涨取最高价，下跌取最低价）；AF 起始 **0.02**，每当创新极值 **+0.02**，上限 **0.2**；价格穿越 SAR 则翻转并重置 AF。 |
| 需要的数据 | 只要 high / low / close |
| **我们能算吗** | **能，递推约 30 行**，不需要任何新数据 |
| **为什么它最值得做** | 它和现有 `exit_price()` 里的 ATR 止损是**同一职能**（都是移动止损），所以可以**直接做 A/B 对比**：同一批选股信号，一边 ATR 止损、一边 PSAR 止损，看哪个回撤更小。这是本次调研里**唯一能用最小改动回答一个真问题**的候选。 |
| 代码形态 | **可跑 Python 脚本**（自带回测） |
| 与现有策略重叠度 | **高**（是止损逻辑的替代，不是新策略） |
| A 股适配度 | ★★★★☆ |
| 落地难度 | **低**（改 `exit_price`） |
| 风险 | PSAR 在震荡市会反复翻转，交易成本吃收益——正好可以用我们引擎的手续费/滑点模型量出来 |

#### 候选 2：均线交叉 + 通道突破（三段式）⭐ 推荐

| 项目 | 内容 |
|---|---|
| 来源 | QuantsPlaybook `C-择时类/均线交叉结合通道突破择时研究/`（申万宏源《均线交叉结合通道突破择时研究》） |
| **一句话赚什么钱** | 金叉只告诉你"方向可能变了"，**不急着买**；等价格突破"金叉之后 N 日内的最高价"才买——用**确认**过滤掉假突破；再用 N 日最低价做跟踪止损。 |
| **核心规则（参数已核实）** | 快线 **9** 日、慢线 **18** 日金叉 → 记录方向；进场 = 价格突破"金叉后 **12** 日内的最高价"（`ChLen=12`）；出场 = **8** 日最低价跟踪止损（`Trail=8`）；信号 **12 日内不作废**；平仓后 **15 日内不再进场**（`ReEntry=15`）；手续费 `FEE=0.003`。 |
| 需要的数据 | OHLC（新增两个滚动极值列：`rolling(12).max(high)`、`rolling(8).min(low)`） |
| **我们能算吗** | **能**，`build_factor_rows()` 里加两列就行 |
| 为什么值得 | 「方向 + 确认 + 跟踪」三段式比现有"ma20/ma60 + MACD 同时判定"更抗震荡；而且**"确认"这一步是我们完全没有的**——现在的策略看到信号当天就买。 |
| 代码形态 | notebook（52 个 cell，含完整推导与回测） |
| 与现有策略重叠度 | 中（仍是趋势跟随，但进场/出场机制不同） |
| A 股适配度 | ★★★★☆ |
| 落地难度 | 低中 |

#### 候选 3：ICU 均线（Siegel 稳健回归）— 可做，但与现有趋势策略重叠度高

| 项目 | 内容 |
|---|---|
| 来源 | QuantsPlaybook `C-择时类/ICU均线/`（中泰证券《"均线"才是绝对收益利器——ICU 均线下的择时策略》） |
| **一句话赚什么钱** | 普通均线是"算术平均"，一根暴涨暴跌就能把均线拽歪；ICU 均线用**稳健回归**（重复中位数 Siegel 1982）拟合最近 N 天价格，取回归线**末端值**当均线——抗异常值。 |
| **核心规则（已读源码）** | `siegelslopes_ma()` 用 `scipy.stats.siegelslopes(price, np.arange(n), method="hierarchical")`，返回 `intercept + slope*(n-1)`（即拟合线在今天的位置）；`ICU_MA = price.rolling(N).apply(siegelslopes_ma, raw=True)`；策略 = 收盘**上穿** ICU 均线买（95% 仓位），下穿卖；`periods=5`；**T 日收盘信号、T+1 开盘成交**。 |
| 需要的数据 | 只要 close |
| **我们能算吗** | 能，但 `rolling.apply` + scipy 会慢（5580 只 × 1200 天），需要向量化或降采样 |
| 代码形态 | **可跑代码**（`icu_ma.py` + `bt_strategy.py`，依赖 backtrader） |
| 与现有策略重叠度 | **高**（就是换一把"趋势尺子"） |
| A 股适配度 | ★★★☆☆ |
| 落地难度 | 中（性能） |
| 风险 | 与 LLT、PSAR 本质是同一件事——**换个尺子**。三个都做没意义，选一个即可。 |

#### 候选 4：LLT 低延迟趋势线 — 与候选 3 同类，二选一

- 来源：QuantsPlaybook `C-择时类/低延迟趋势线与交易择时/`（广发证券）
- 核心：二阶低通滤波器递推，`α = 2/(d+1)`（d 为周期）；`LLT = (α−α²/4)·P_T + (α²/2)·P_{T−1} − (α−3α²/4)·P_{T−2} + 2(1−α)·LLT_{T−1} − (1−α)²·LLT_{T−2}`。alpha 越小越平滑、延迟越高。
- 与 ICU 的关系：**同一个目的、不同滤波器**（一个是稳健回归，一个是低通滤波）。二选一。
- A 股适配度：★★★☆☆

#### 候选 5：点位效率理论（兴业证券，波段划分）— 落地成本高

- 来源：QuantsPlaybook `C-择时类/基于点位效率理论的个股趋势预测研究/`，`py/Approximation.py`（21KB）+ 56 个 cell
- 核心：先用 MACD 的 DIF/DEA 把价格序列切成"上笔/下笔"，再自动修正异常端点，然后算"点位效率"（同样涨跌幅走过的空间大小），判断趋势质量。
- **评价**：这是**波段划分工具**，和我们已有的 `factors/chan.py`（缠论笔/线段/中枢）定位重叠。若要做，应是"升级 chan.py"而不是"新增策略"。本阶段不推荐。
- A 股适配度：★★★☆☆

#### 候选 6：技术分析算法框架与实战（中泰证券，形态识别）— ❌ 不推荐

- 来源：同仓库 `C-择时类/技术分析算法框架与实战/Technical Pattern Recognition/`（`technical_analysis_patterns.py` + `timing_signal.py` + 22 cells）
- **劝退理由**：它给的是"形态出现后未来 N 天的收益统计"，**没有仓位规则、没有止损规则**；作者自己在 notebook 里留 TODO，承认收益没有减掉指数基准。这是研究素材，不是策略。
- A 股适配度：★★☆☆☆

#### 候选 7：Dual Thrust — ❌ 数据不匹配

- 规则本身很简单：`range = max(HH − LC, HC − LL)`（N 日最高价−最低收盘价、最高收盘价−最低价取大者），上轨 = 当日开盘 + K1×range，下轨 = 开盘 − K2×range，`param=0.5` 对称。
- **劝退理由**：这个策略是为**分钟级、可做空、24 小时交易**的外汇/期货设计的；A 股只有日线、T+1、不能做空。用日线算出来就是"开盘价 ± 半日振幅"，等价于一个粗糙的突破策略，没有意义。
- A 股适配度：★☆☆☆☆

#### 候选 8：Qbot 网格交易 — ❌ 接口形态冲突

- 规则：设中枢 p、格宽 w、单次数量 v，涨到 `p+w+0.01` 减 v，跌回 `p+w` 加 v，超过 `p±4w` 不处理。
- **劝退理由**：①文档里"### 策略实现"的 python 代码块是**空的**，无回测；②它是**仓位管理**策略，不是选股策略，需要同时盯着几百只票的挂单——和"盘前出一份信号列表"的接口形态根本冲突；③A 股 T+1，当天买了不能当天卖，网格的一半动作做不了。
- A 股适配度：★☆☆☆☆

### 3.2 动量轮动

**这一类要解决什么**：现有动量策略只做"个股横截面排序"——在全市场里挑近期涨幅大的。它缺的是**"在板块之间换仓"**的能力：2023 年 AI、2024 年红利、2025 年的主题行情，赚的都是"站对队"的钱，而不是"选对票"的钱。

#### 候选 1：RRG 行业轮动（相对旋转图）⭐ 强烈推荐

| 项目 | 内容 |
|---|---|
| 来源 | `hugo2046/QuantsPlaybook` → `C-择时类/相对旋转图RRG行业轮动/`（★6778，**license 为 null，无许可证**） |
| 原始出处 | 西部证券《指数化配置系列研究（6）：相对旋转图 RRG 框架下的行业研究》（冯佳睿/陈曼莲） |
| **一句话赚什么钱** | 行业像风车一样轮流转，每个行业在"领先→转弱→落后→转强"里循环。RRG 把这个循环画成一个四象限图，我们买"正在转强"的那几个行业。 |

| 进出场 | 换仓日收盘出信号、**次日开盘成交**（无日内前视） |

### 3.3 均值回归

**这一类要解决什么**：现有均值回归策略已经在做"偏离均线太多就买"，它缺的不是选股逻辑，而是**"什么时候该用均值回归"的开关**——震荡市均值回归赚钱，单边趋势市均值回归天天被套。这一类里最有价值的候选全部是**"状态开关"**，而不是新的选股公式。

#### 候选 1：RSRS 阻力支撑相对强度（择时开关）⭐ 推荐

| 项目 | 内容 |
|---|---|
| 来源 | QuantsPlaybook `C-择时类/RSRS择时指标/`（光大证券《基于阻力支撑相对强度的择时体系》） |
| **一句话赚什么钱** | 用"最高价对最低价的回归斜率 β"衡量买盘强度：β 高说明一有低点就被买走（支撑强），β 低说明一有高点就被卖（阻力强）。β 相对自己历史的 z-score 高就持仓、低就空仓。 |
| **核心规则（参数已核实）** | 对最近 **N=18** 天的 `high` 和 `low` 做 OLS 回归取斜率 β；在最近 **M=600** 天上对 β 做标准化 `z = (β − mean)/std`；`z > S=0.7` 持仓，否则空仓。<br>**改进版（钝化）**：`score = z(β) × R^(4 × quantile(β))`，R 为回归 R²——用 R² 惩罚"拟合很差的强斜率"。 |
| 需要的数据 | 只要 high / low |
| **我们能算吗** | **能，纯计算**；且我们已经有一个 `factors/regime.py` 的 `detect_regime()`，RSRS 可以和它拼成一个更强的市场状态判断 |
| 关键定位 | **它是择时，不是选股**。正确用法：接在 `BacktestConfig.market_timing`（或两段式流程的第一段"今天该不该重仓"）上，而不是当第 8 个选股策略 |
| 代码形态 | **可跑代码**（`py/RSRS.ipynb` + `RSRS改进.ipynb` + 3 份研报 PDF） |
| 与现有策略重叠度 | **低**（现有策略没有"市场状态开关"） |
| A 股适配度 | ★★★★☆ |
| 落地难度 | 中（要接进回测/选股流程，不是独立策略） |
| 风险 | 研报用的是指数级参数；个股级要重新标定；600 天窗口意味着回测前两年没有信号 |

#### 候选 2：QRS（RSRS 的解析解版本）— 与候选 1 同源，二选一

- 核心：`β = std(high) / std(low) × corr(high, low)`，用**相关系数的平方**加权，`corr²` 替代 R²。
- 与 RSRS 的关系：同一个思想的两种实现，**RSRS 用回归 R²、QRS 用 corr² 且能解析求解（不用跑 OLS，快很多）**。
- 建议：如果我们已经有 5580 只票要算，**QRS 的性能优势是决定性的**。→ 如果要落地，优先 QRS 的实现方式。
- A 股适配度：★★★★☆

#### 候选 3：布林带 W 底形态 — 判定太脆弱

- 规则：布林带 `period=75`，`alpha=beta=0.0001`；识别"双底 + 突破上轨"的 W 形态后买入。
- **问题**：`alpha/beta=0.0001` 是**外汇量级**的参数（波动小才需要这么小的带宽），照搬到 A 股会立刻被击穿。且"双底"的形态判定对噪音极其敏感，换一个时间段识别结果就变。
- 结论：可参考"形态 + 突破确认"的组合思路，**不建议照搬**。
- A 股适配度：★★☆☆☆

#### 候选 4：行业指数 NH-NL 顶部/底部信号 — 有资料但需重构

- 来源：QuantsPlaybook `C-择时类/行业指数顶部和底部信号/`（README 只有一行网盘链接，**规则全在 `core.py` 里**）

- A 股适配度：★★★☆☆

### 3.6 事件驱动

**这一类要解决什么**：事件驱动 = 用"某件具体的事发生了"来选股（涨停、开板、财报超预期、资金异动、可转债联动）。它和前面五类的根本区别是：**前面五类靠"状态"，这一类靠"事件"，因此对数据的要求高一档**。这一类也是本次调研里**最需要说"不行"**的一类。

#### 候选 1：涨停板 / 连板接力 ⭐ 最有潜力，但需要先补数据

| 项目 | 内容 |
|---|---|
| 来源 | 概念来自 `123quant/QMT-QuantLimit`（★222）+ A 股打板生态；**规则思路是公开的，价值在数据** |
| **一句话赚什么钱** | 涨停代表资金一致性极强。首板次日通常有溢价（隔日冲高）；连板到第 3、4 板时情绪最热但也最危险。赚的是**情绪溢价**。 |
| **核心规则** | ①在昨日涨停池里筛（首板 / 2 板 / 3 板以上分开看）②按封单强度（`seal_fund`）、封板时间（`first_seal`）、炸板次数（`break_count`）排序 ③次日开盘买入、持有 1–2 日 ④炸板（`break_count>0`）和尾盘偷袭（`last_seal` 晚于 14:30）的降权 |
| **数据现状（关键）** | 我们**已经在采集** `data/processed/market/<date>/limitup.parquet`，字段非常完整：**连板数 `boards`、封板资金 `seal_fund`、首次/最后封板时间、炸板次数 `break_count`、流通市值 `float_mv`、所属行业 `industry`**（来源 `ak.stock_zt_pool_em`）。**但只有 2026-10-27 和 2026-10-28 两天。** |

#### 候选 2：CCK 羊群效应（市场状态指标）⭐ 纯现有数据可算

| 项目 | 内容 |
|---|---|
| 来源 | QuantsPlaybook `C-择时类/基于CCK模型的股票市场羊群效应研究/`（国泰君安《数量化专题之一百二十二：基于 CCK 模型的股票市场羊群效应研究》） |
| **一句话赚什么钱** | 平时个股涨跌各走各的（离散度大）；一旦大家不管好坏一起买/一起卖，就进入"羊群状态"。**羊群效应出现后，市场往往加速**——所以它是一个"要不要重仓"的开关。 |
| **核心公式（已核实）** | 横截面绝对偏差：`CSAD_t = (1/N) × Σ|R_{i,t} − R_{m,t}|`<br>二次回归：`CSAD_t = α + β1·|R_{m,t}| + β2·R_{m,t}² + ε_t`<br>**羊群效应 = β2 显著为负**（理论上离散度应随市场涨幅平方增长，若反而下降，说明大家在趋同） |
| **交易信号（已核实）** | `CSAD_t < 0 且 指数平移收益率 > 0` → 开仓；用 22 个交易日（一个月）滚动窗口估计 β2；信号消失即平仓 |
| 回测结论（原作者） | 除上证 50 稳定性较差外，其他宽基指数上**夏普 > 1**（这是本次调研里少数"作者自己给了正面且具体结果"的候选） |
| 需要的数据 | 全市场个股日收益率 + 指数收益率——**我们全有** |
| **我们能算吗** | **能，纯 pandas**。5580 只票算 CSAD 是一行 groupby；滚动回归用 numpy polyfit 即可。 |
| 定位 | **市场状态开关**，不是选股策略。正确用法：接在仓位控制/`market_timing` 上，或作为"今天该不该开新仓"的门槛 |
| 代码形态 | notebook（136 个 cell，含完整推导 + 多指数回测） |
| 与现有策略重叠度 | **低** |
| A 股适配度 | ★★★★☆ |
| 落地难度 | **低中**（数学简单，但要接进流程） |

- 结论：**不推荐现在做**。

### 4.2 缺的字段，按"补起来的代价"分三档

**A 档：不用补，现在就能做**（本报告 Top 3 全在这一档）

| 能力 | 靠什么算出来 | 备注 |
|---|---|---|
| 小市值 / 微盘 | **流通市值 = 成交额 ÷ 换手率**（换手率取小数）。已实测验证，见下方 | **可以算出 2021 年至今全历史的每日流通市值**，不需要新数据源 |
| 换手率类因子 | `turnover` 直接可用 | 2021 年起齐全 |
| 筹码分布（获利盘比例等） | 用 OHLCV + 换手率反推换手衰减模型 | QuantsPlaybook 的 `cyq.py` 就是这么干的 |

> | 股票 | 收盘价 | 成交额 | 换手率 | 推算流通市值 | 常识值 | 结论 |

**B 档：补一个字段就能做**（建议做，成本可控）

### 4.3 关于"字段只多不少 + LLM 兜底"（你的要求）

你说的两层意思我都记下了，对应的设计在第 7 节：

- **字段只多不少**：日线表结构**不删不改**，新字段一律**加列**（`turnover` 已经是这么加的）；`bars_map` 消费方用 `.get()` 取列，缺列不报错、走降级默认值。
- **LLM 自定义策略兜底**：现在 `strategy/custom.py` 已经有一套哨兵值机制（比如 `dev_ma=20`、`mom_min=-100` 表示"禁用该规则"）。新增字段同样走这套：**字段缺失 → 该条规则自动禁用 → 在信号报告里打 `degraded` 标记**，用户能看到"这条策略今天少算了哪一条"。

## 5. Top 3 组合建议

先说结论，再说为什么。

### 5.1 如果只能做一件事

**做「均线收敛因子 PCF / TRCF」。**

理由：它**不改任何策略的结构**，只是在 `build_factor_rows()` 里加两列；但加上之后，**全部 7 个策略都会多一个"波动结构"维度的输入**。一个 `rolling.std()` 的成本，换 7 个策略同时受益——这是本次调研里投入产出比唯一"离谱"的候选。

### 5.2 如果做三件事（推荐）

| 顺序 | 做什么 | 预计工作量 | 为什么排在这个位置 | 怎么验证 |
|---|---|---|---|---|
| **①** | **收敛因子 PCF / TRCF**（3.4 候选 1） | 半天 | 成本最低、惠及全部策略、纯现有数据 | 同一策略加/不加该因子，跑同一区间对比 |
| **②** | **动量因子方向修正**（3.2 候选 2） | **1 小时** | 这是**修 bug 不是加功能**：现有动量策略用 20 日涨幅，而研报实测 A 股裸涨幅动量 **IC 全为负**。改 `MA_L/close` 只需两行 | 只跑动量策略，改前/改后对比 |
| **③** | **RRG 行业轮动**（3.2 候选 1） | 2–3 天 | 唯一能补上"行业/轮动"这个**全新的资产维度**（现有 7 个策略完全没有）；而且它是本次调研里**代码和文档最完整**的一个 | 先只做"行业指数 + 四象限选行业"，不碰个股；用行业等权组合回测，能跑通再往下做 |

**为什么 ③ 放在 2–3 天而不是更长**：因为第一步只需要做"行业指数聚合 + 四象限判定"这一半。**如果行业层这一步就没有超额，后面的个股层不用做了**——这是成本最低的证伪路径。

### 5.3 排在 4–6 位（有价值但先不做）

| 候选 | 为什么先不做 |
|---|---|
| **小市值**（3.5） | 空白最大，但**Qbot 自己的稳健性表显示 2005–2015 年化仅 0.99%、2015–2020 仅 0.85%、最大回撤 59.5%**。这不是"新策略"，是"高波动风格暴露"。要做的话**必须先把过滤纪律（CTBZStock 那套）和市值代理公式的误差量级确认清楚**，否则回测结果不可信。 |
| **PSAR 止损 A/B**（3.1 候选 1） | 成本也很低（改 `exit_price`），但它改善的是**已知的弱环节**而不是新收益来源。适合在做完 ①② 之后顺手做一次 A/B。 |
| **筹码因子 / CGO**（3.4 候选 2） | 好因子，但要**脱离 qlib 重写**（原实现绑死 `ExpressionOps` + numba）+ 5580 只 × 1200 天的累积计算，成本是收敛因子的 5–10 倍。等 ①② 验证完因子确实有用，再投入。 |
| **RSRS / QRS 市场开关**、**CCK 羊群效应** | 数学都简单、都能算，但它们改的是**"仓位/择时层"**，而不是"选股层"。先把选股因子做完，再动仓位层，否则两个变量同时变，回测结果说不清是谁的功劳。 |
| **涨停板 / 打板**（3.6 候选 1） | **不是策略问题，是数据+成交假设问题**。必须先回补 2020–2026 涨停池，并且设计"买不进"的成交概率假设。**在没解决成交假设之前，这个方向的回测结果一定是虚高的**，不建议投入。 |

### 5.4 一个必须提前说清楚的验证纪律

我们的回测区间是 **2021-10 到 2026-10，约 5 年**，而且这几年 A 股经历了：2021 新能源泡沫、2022 熊市、2023 AI、2024 年初微盘股踩踏、2024 下半年政策反转。**5 年只够覆盖两三轮风格**，任何策略在这 5 年里的年化数字都有巨大的运气成分。

所以建议的验证标准不是"年化多少"，而是这四条：

1. **换手率**——新因子会不会让策略每周买卖十几次？交易成本吃掉收益的策略不值得做。
2. **最大回撤**——比年化重要。多因子策略的价值在于"跌得少"，不是"涨得多"。
3. **分年度看**——2022 年（熊市）、2024 年（微盘踩踏）这两段能不能活下来，比全区间年化更说明问题。
4. **参数敏感度**——把窗口从 20 改成 30 就崩的策略，是过拟合。

> 这四条也正好是现有 `metrics.py` 里已经能算的（`total_return / max_drawdown / win_rate / trade_count`），基本不需要新写代码。

### 5.5 与旧草案的差异（为什么我改了推荐）

最初的草案推荐的是「RRG / 筹码因子 / 小市值+换手」。读完源码和研报后，我把它改成了上面这组，原因：

- **筹码因子从第 2 降到第 5**：原实现绑死 qlib，重写成本被低估了；
- **小市值从第 3 降到第 4**：Qbot 自己的稳健性表是反对证据，我不能只引用它"年化 28%"的那一段；
- **收敛因子升到第 1**：它的成本被我低估了——读完公式才发现是**一个 `rolling.std()`**；
- **动量方向修正进 Top3**：这不是新策略，是**现有策略里的一个方向性错误**，优先级应该高于任何新增。

## 6. 两段式设计：先选类型，再让 LLM 发挥

这是你 2026-10-29 提的想法，我认为方向对，而且**正好解决"字段不够"的痛点**。这里给一个能直接开工的设计。

### 6.1 为什么不直接让 LLM 自由写策略

现在 `strategy/codegen.py` + `custom.py` 是**一段式**：用户描述 → LLM 生成打分规则 → 直接跑。问题是：

- LLM 不知道我们有哪些字段，容易写出"取市值因子"这类**根本取不到的规则**，然后静默失败或返回空结果；
- 生成结果无法归类，用户看不出"这到底是趋势策略还是事件策略"；
- 出问题时无法定位是"类型选错了"还是"规则写错了"。

### 6.2 两段式：类型先定骨架，LLM 只填血肉

```
第一段：选类型（6 选 1，下拉框）
   趋势跟随 / 动量轮动 / 均值回归 / 多因子 / 小市值 / 事件驱动
        ↓ 每种类型带一份「骨架 + 该类型的可用字段白名单 + 默认参数」
第二段：LLM 在这套约束内发挥
   ├─ 只能用白名单里的字段（越界即拒绝，不会写出取不到的规则）
   ├─ 没填的参数走三层默认值
   └─ 生成的策略自动带 type 标签，可归类、可复用
```

### 6.3 三层默认值兜底（关键机制）

| 层 | 内容 | 例子 |
|---|---|---|
| 第 1 层：类型默认值 | 每种类型预置一套"能跑起来"的参数 | 小市值：`mv_pct=0.2`（取市值最小 20%）、`min_amount=5000万`、`hold_days=20` |
| 第 2 层：全局默认值 | 跨类型的通用兜底 | `atr_m_exit=3.0`、`atr_n_stop=3.0`、`top_n=5` |
| 第 3 层：缺字段即禁用 | 字段不存在 → 该条规则跳过 + 打 `degraded` 标记 | 缺"财报披露日" → 财报类规则禁用，用报告期+60天替代，并在报告里注明 |

**效果**：用户哪怕只写一句"我想买便宜的半导体小公司"，也能生成一个**不会崩、行为可解释**的策略，而不是报错或悄悄返回空列表。

### 6.4 落地成本

| 部分 | 工作量 | 说明 |
|---|---|---|
| 6 个类型的骨架 + 字段白名单 | 中 | 本次调研的六大类正好是这 6 个骨架 |
| `custom.py` 改造成"类型 + 覆盖参数"结构 | 中 | 现有哨兵值机制可复用，不用重写 |
| UI 加一个"策略类型"下拉框 | 小 | 现有自定义策略页加一个 selectbox |
| 三层默认值表 | 小 | 纯配置 |

> 建议：**等本次选型拍板后再做**。因为第 1 层的"类型默认值"就是选出来的策略，选型没定之前写默认值是白写。

| 规则 | 扣分 | 触发条件 |
|---|---|---|
