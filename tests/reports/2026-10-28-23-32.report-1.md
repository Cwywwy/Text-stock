## 失败详情与原因

本轮最终无失败。过程中出现一次自伤事故，已修复并复盘：

- **现象**：用 PowerShell 5.1 的 `Get-Content -Raw` + `Set-Content -Encoding UTF8` 批量替换
  `updater.py` / `classification.py` / `announcements.py`，三文件被按 ANSI(GBK) 解码再写 UTF-8，
  中文注释变乱码，`pytest` 收集阶段报 `SyntaxError: invalid character '\uff04'`。
- **处置**：`git checkout --` 还原三个文件，改用 Python 脚本（显式 `encoding="utf-8"`）重放全部替换，
  复跑全绿；随后加乱码自检，结果为空。
- **教训**：本机是 PowerShell 5.1，改 UTF-8 源码一律用 `edit` 工具或 Python 读写，
  禁用 `Get-Content`/`Set-Content` 组合。
