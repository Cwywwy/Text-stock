## 3 Phase 19：双均线三档择时（默认关闭）

### 3.1 规则（`src/stock_plan/factors/timing.py`）

| 档位 | 条件（用当日收盘算，次日生效） | 目标总仓位 |
| --- | --- | ---: |
| 满仓 | `close ≥ MA20` | 100% |
| 半仓 | `close < MA20`，且不满足空仓条件 | 50% |
| 空仓 | `close < MA60` 且 `MA20[t] < MA20[t-5]`（斜率向下，**相等不算**） | 0% |

预热不足（均线缺值）默认按满仓处理，避免开头几周被动清仓。

### 3.2 引擎接入（`src/stock_plan/backtest/engine.py`）

- 新增 `BacktestConfig.timing_tier: str = "off"`（`"off"` / `"dual_ma"`），`__post_init__` 校验非法值并给中文报错。
- 档位序列按交易日 `reindex(method="ffill")` 后 **shift(1)**，当日只使用上一交易日收盘算出的敞口 → 无未来函数。
- 每日在「持仓检查之后、买入之前」执行 **真实降仓**：目标市值 = `(现金 + 持仓市值) × 敞口`，按比例卖出超额部分，100 股整手，不足 100 股不卖；当日买入的仓位因 T+1 不参与当日降仓；跌停/停牌跳过并计入「未能降仓」。
- 买入侧同样封顶：`新买入预算 = min(现金/top_n, 目标市值 - 当前持仓市值)`，**只封顶不追买**。
- `off` 分支不构造档位序列、不进入任何降仓代码；旧「弱择时」（`market_timing`，仅对新买入减半）保留，与新档位同时开启时**新档位优先**（`use_weak_timing = market_timing and not use_tier_timing`）。
- 行业轮动 `run_industry_rotation(..., timing_tier="off")` 同一口径（组合层按等权指数算档位、按档位缩放目标权重、10bp 成本）。

### 3.3 其它改动

- `conv_variant`（趋势跟随 / 突破）：`pcf`（默认）/`vcf`/`pvcf`/`multi`，仅改变 `conv_weight × z(...)` 用哪一列，默认 `pcf` 与 Phase 7 完全一致。
- UI 三页（回测 / 策略对比 / 可视化构建）新增「大盘择时档位」下拉，默认「关闭（满仓）」；弱择时复选框文案改为「弱择时（仅对新买入减半，旧行为）」。缓存键（`backtest_cache.py`）加入档位，避免切档位读到旧缓存。
