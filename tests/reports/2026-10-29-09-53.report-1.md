## 2 改动清单

| 文件 | 改动 |
| --- | --- |
| `src/stock_plan/backtest/walkforward.py` | `walk_forward(..., prepared: PreparedBacktest \| None = None)`；未传时对整段 bars_map **只 prepare 一次**，训练段/测试段所有 `run_backtest` 复用；窗口切分、每窗口 `filter_universe`/交易日/基准仍按窗口重算，不改变语义 |
| `src/stock_plan/signal/generator.py` | `_collect_ranked` / `generate_signal_report` / `generate_signals_with_report` 增加 `prepared` 参数；传入时**不再调用 `load_market_maps`**（直接用 prepared 的 stock_list/bars_map/fund_map），`build_factor_rows(..., prepared=prepared)`；未传时行为不变。注意：`_collect_ranked` 入口仍会创建 `Storage()` 实例（廉价、惰性连接，不读 parquet/不查库；调用方传 storage 时不创建），不宣称「不创建 Storage」 |
| `src/stock_plan/strategy/builtin.py` | `build_factor_rows(..., prepared=None)` + 私有 `_factor_row_from_table()`：命中因子表且行数一致时直接取末行，省掉 `compute_technical`/收敛/均线比值重算；两处回落到日线切片保证语义：`high20` 用 `close.iloc[-20:].max()`（rolling 遇 NaN 整窗 NaN，`Series.max` 跳过 NaN，不能混用）、`avg_amount20` 用 `amount.tail(20).mean()`（rolling 不足 20 根为 NaN，`tail.mean` 取现有行）；<20 根 high20/ratio 回退、<21 根 `mom_ret=0` 与旧路径一致；缺表/行数不匹配自动回落逐 code 重算。26 列列集与数值不变 |
| `tests/test_walkforward_prepared_parity.py`（新增） | 合成 4 code × 300 根、2 窗口：plain vs prepared 的 `windows`/`oos_metrics`/`oos_equity`/`oos_trades` 逐值一致 + prepared 只读快照未被修改 |
| `tests/test_factor_parity.py` | 新增 `test_build_factor_rows_prepared_matches_plain`：边界物料（240/20/19/21/5 根、缺 amount、含 NaN 收盘、原始指标与已算分数两种 fund），列集/顺序/`assert_frame_equal(check_exact=True)` 逐值一致 |
| `tests/test_signal_report.py` | 新增 `test_combined_call_with_prepared_matches_plain`：prepared 路径用 `_NoLoadStorage` 断言不调用 `load_market_maps`，信号 list 与 `report.cache_payload()` 逐值相同 |
| `tests/test_engine_defects.py` | fake `run_backtest` 签名补 `prepared=None`（walkforward 现在会传该关键字），2 行 |
